# Flutter 3.50 upgrade — brief

**What:** Move CI and the release builds from Flutter 3.47.1 to the latest stable, **3.50.0** (Dart 3.14, released 2026-11-11). This includes the Android toolchain bumps that 3.50 requires.

**Why:** The owner asked for the latest Flutter and forui (2026-11-12). forui 0.27.7, the latest version, is the base of the UI redesign.
