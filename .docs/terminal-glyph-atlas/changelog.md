# Changelog

- 2026-11-12 — Baseline (profile, macOS, 121x40, `frames-credit.json`): cat plain 0.38 s / color 0.28 / unicode 0.12 / tui 0.21; flood build p90 ≈ 6 ms, raster p50 ≈ 3.5–3.7 ms, ~30 terminal repaints/s.
- Probe: Skia subpixel model (4 x phases), y snapping, tint vs colored tile (65 vs 1 level max diff) → tiles keyed by color.
- `feat(xterm)` glyph atlas text path + pixel tests (tolerance 1/255). First test run: underlined cells differed by 14 levels (decorations are rects at the exact fractional x, not phase-snapped) → fallback; merged background runs differed at fractional y (per-cell rects overlap and double-blend their AA rows) → merge only when rows are whole device pixels; keyword foregrounds over atlas glyphs differed by 2 (two stacked tile composites) → paragraphs. Mutations (no ink flush, phase 0, ignored y fraction, always merge) all fail the tests by 158–187 levels.
- Profile E2E, atlas, 30 fps throttle: raster p50 3.5 → 0.9 ms, tui build 4.1 → 0.8 ms, but plain/color build still ~4.5 ms: CPU samples showed `paintKeywordForeground` building a new paragraph per matched char (default rules color "info"/"debug") = 12.6% of UI samples vs 2.8% for the atlas line path → `perf(xterm)` cache those paragraphs per (char, color). Repaint-frame build then ~1.1 ms.
- `fix(xterm)`: `_compensateScrollbackTrim` threw on a negative (overscrolled) offset (`clamp(0, pixels)`), intermittently failing the perf harness (also in the pre-atlas `drive2.log`).
- `perf(terminal)`: `floodInterval` 33 → 16 ms.
- Final profile E2E (121x40, 60 fps): cat plain 0.365/0.345/0.348 s, color 0.328/0.255/0.254, unicode 0.164/0.125/0.125, tui 0.154/0.145/0.155; repaints/s during floods ≈ 55 / 56 / 50 / 54 (was ≈ 30); repaint-frame build p50/p90/p99 plain 1.10/1.22/2.93, color 1.12/1.27/3.25, tui 0.79/0.96/4.04 ms; raster 0.93/1.05/4.36, 0.90/1.37/4.21, 0.62/1.03/3.72 ms (p99 = warm-up frames before tiles are admitted); 0 frames > 16.7 ms on plain/color/tui (unicode 2, as before).
- `integration_test/terminal_atlas_pixel_test.dart` on macOS (backend: Impeller): every case ≤ 1 level at dpr 1 / 1.5 / 2 with fractional origins — the Skia phase model holds on Impeller.
